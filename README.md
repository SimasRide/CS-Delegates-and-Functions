# CS-Delegates-and-Functions
Delegates, Lambda Expressions, métodos anónimos e delegates genéricos (Func, Action e Predicate).  Inclui também exemplos práticos de passagem de parâmetros (ref, out e in), métodos estáticos e de instância, parâmetros opcionais (params), iteradores (yield return) e operações matemáticas, como cálculo de médias, valores mínimos e máximos.
