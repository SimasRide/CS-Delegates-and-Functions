# C# Delegates and Lambda Expressions

A practical C# console project developed as part of my learning process, focused on understanding how delegates work and how they can be used to reference and execute methods dynamically.

The project includes examples using custom delegates, lambda expressions, anonymous methods, Func, Action and Predicate. It also explores concepts such as ref, out and in parameters, static and instance methods, optional parameters, params and yield return.

The exercises include mathematical operations, calculating averages, finding minimum and maximum values, and generating number sequences based on specific conditions.

The main goal is to improve my understanding of C# and become more comfortable working with its programming concepts through hands-on practice.
